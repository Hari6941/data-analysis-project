# Data Analysis Project

This is a minimal Python project for data analysis using **pandas**. It follows a basic layout:

```
data-analysis-project/
├─ src/
│  └─ datas_main.py
├─ tests/
│  └─ test_datas_main.py
├─ requirements.txt
└─ README.md
```

The `src/datas_main.py` module demonstrates importing pandas with a `datas_` prefix and includes a simple function you can extend.

## Setup
```bash
python -m venv venv
venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Running Tests
```bash
pytest
```
